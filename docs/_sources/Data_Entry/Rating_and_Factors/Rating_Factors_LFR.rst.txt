Rating Factors for LFR
===========================

**Table** :ref:`tbRatingFactorsLFRDef`

**PURPOSE**

Use this table to create a library of factors that are used when
computing the member capacity and rating for **LFR** analysis. 
Rating factors are applied on a per member basis, thus the name 
given for a set of factors on this table is referenced by the 
following member entries:


* :ref:`Input Stringer Definition`
* :ref:`Input Truss Member`


.. note::

    It is advised that you use the same 'name' for LFR and LRFR.
    This way you can easily switch from a LFR to a LRFR analysis.

**Parameters**

  .. Include:: ../../tables/tbRatingFactorsLFRDef.txt

* **Name**

   Name for set of factors. This name is referenced in :ref:`Input Stringer Definition`  and :ref:`Input Truss Member`

* **Mode**

  Each set of factors can have multiple lines of data, one for each:

  * INV : Inventory
  * OPR : Operating 
  * LEG : Lagal
  * PER : Permit
