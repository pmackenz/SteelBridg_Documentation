Input Truss Member
---------------------

**Table** :ref:`tbTrussMember`


**PURPOSE**
    Define truss member locations.  

**Parameters**

  .. Include:: ../../tables/tbTrussMember.txt


.. note::

    If the Local Buckling length is not entered, then no local buckling length
    check is performed.  A warning is issued that no local buckling length check
    has been done.


* If a member's `TCCode` is `T` then that member will only be checked for tension rating, 
  and if it is `C` then that member will only be checked for compression rating.

* The `Type` field is [B|T|C|D|V] for code: BOTTOM, TOP, CORD, DIAG, VERT
  If B,T,or C use Mom rider only loads. If D or V use Shr rider only. Blank=both riders.

* The effective length of a member is it's node to node distance times the effective length factor.  
  For calculations that involve the major axis of bending, bending about the local Z axis, the effective 
  length factor <span style="font-weight:bold; ">MajEffL</span> is used.  
  For bending about the minor axis, the local Y axis, the factor <span style="font-weight:bold; ">MinEffL</span> is used.</P>
