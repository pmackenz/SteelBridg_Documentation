Transverse Load Combinations
=============================

**Table**  :ref:`tb2DTLoadCombDef`

**PURPOSE**
    Define the load combinations to be used on the transfer model. The tbLoadCombDef is NOT 
    used for transverse analysis. 
    The resulting reactions forces from these loads will be directly applied to the floor beam.
    ( :ref:`Transverse Reactions` )
