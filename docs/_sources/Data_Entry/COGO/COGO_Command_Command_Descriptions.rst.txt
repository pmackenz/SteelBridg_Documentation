COGO Command: Command Descriptions
====================================

**Table** :ref:`tbCogoCommandData`

**PURPOSE:**

Use this table to enter basic bridge geometry locations. These locations will be used to define nodal boundaries,
stringers, floorbeams, truss members, and truck path.

For historical reasons BRIDG includes a near complete COGO package which has many features not needed for 2D data input. 
Only these 3 commands are commonly used:

* :ref:`COGO Command: STOR`   (Enter location using coordinates)
* :ref:`COGO Command: OFFSET` (Locate a new point from an existing point)
* :ref:`COGO Command: PATH`   (Define a path. Mostly used for truck path)

    * - Command

    * - :ref:`Input COGO Command Data`
      - COGO input command summary

      - To locate a new point between two existing points

      - To divided the line from NF to NT into NP+1 equal segments.
    * - :ref:`COGO Command: EQ/L`
      - To establish NP point along a line from point NF to point NT.

    * - :ref:`COGO Command: MAPHV`

    * - :ref:`COGO Command: PAST`

    * - :ref:`COGO Command: STOR`
      - To input the known (or assumed) coordinates of selected points.
    * - :ref:`COGO Command: VCURV`
      - To specify a vertical curve.
    * - :ref:`COGO Command: Example`

    * - :ref:`COGO Command: BIAS`
