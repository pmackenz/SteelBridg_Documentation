Finite Element Analyzer

Description

The BRIDG program has a built in 3D finite element analyzer that it uses (in 2D mode) and it can be used as a standalone FEA engine.

The steps to using the FEA are:

  1. Generate a FEA file using BRIDG on any BDF file. This gives you an example input to work with. ( Finite Element Analysis - File Generation )

  2. Cut and paste the FEM model section from the generated FEA file and create a F3D file ( Finite Element Analysis - The F3D file )

  3. Edit this file as needed.

  4. Run the FEA ( Finite Element Analysis - Running the F3D file )
