Rating Factors for LRFR

Table tbRatingFactorsLRFRDef

PURPOSE

Use this table to create a library of factors that are used when computing the member capacity and rating for LFFR analysis. Rating factors are applied on a per member basis, thus the name given for a set of factors on this table is referenced by the following member entries:

  • Input Stringer Definition

  • Input Truss Member

Note

It is advised that you use the same ‘name’ for LFR and LRFR. This way you can easily switch from a LFR to a LRFR analysis.

  • Name

    Name for set of factors. This name is referenced in Input Stringer Definition and Input Truss Member

  • Mode

    Each set of factors can have multiple lines of data, one for each:

    • INV : Inventory

    • OPR : Operating

    • LEG : Lagal

    • PER : Permit

    • EV : Emergency

  • Resistance Factors

    Resistance factors reside in Input Analysis Controls
